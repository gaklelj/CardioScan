# Запись с ESP32 + ADS1293

Основной скетч: `esp32_ecg_wifi/esp32_ecg_wifi.ino`.
`../firmware_synthetic_v2.ino` — отдельная самостоятельная тестовая прошивка:
генерирует сигнал без ADS1293 и автоматически отправляет его одновременно
по USB (115200 бод) и Wi-Fi (те же сеть, пароль и TCP-порт). Частота 125 Гц,
имитация пульса 75 уд/мин. Это искусственные данные, а не измерения человека;
сохранённые тестовые записи помечайте как синтетические.
В сигнал добавлены слабый случайный шум, малая помеха 50 Гц, дрейф базовой
линии и плавное изменение амплитуды на ±1,2%. Это приближённая форма для
проверки передачи и отображения, а не клинически проверенная модель ЭКГ.
Для её загрузки поместите этот единственный файл в папку `firmware_synthetic_v2`,
откройте его в Arduino IDE, выберите ESP32 Dev Module и загрузите.
Для USB закройте монитор порта IDE и выберите USB в CardioScan.
Для Wi-Fi подключитесь к CardioScan-ESP32 и выберите Wi-Fi в CardioScan.
Все остальные инструкции ниже относятся к прошивке реального ADS1293.

## Загрузка

1. Отключите электроды от человека перед подключением USB и прошивкой.
2. Откройте основной скетч в Arduino IDE. Имя папки уже соответствует имени файла.
3. Установите пакет плат **esp32 by Espressif Systems**, версия 3.x.
4. Выберите **ESP32 Dev Module** и COM-порт классического ESP32 DevKit V1.
   ESP8266, ESP32-C3 и ESP32-S3 этой конфигурацией не поддерживаются.
5. Нажмите «Загрузить». Если плата не входит в загрузчик автоматически,
   удерживайте BOOT во время появления `Connecting`, затем отпустите.
6. Откройте монитор порта на **115200**. Ожидаются `REVID=0x01`, адрес TCP
   и `Started`. При ошибке проверки регистров сбор данных не запускается.

## Соединения

| ADS1293 | GPIO ESP32 |
| --- | --- |
| SCLK | 18 |
| SDO / MISO | 19 |
| SDI / MOSI | 23 |
| CSB | 27 |
| DRDYB | 34 |
| GND | GND |

RSTB должен удерживаться модулем в высоком уровне; прошивка им не управляет.
Нужен кварц 4,096 МГц. GPIO34 не имеет внутренней подтяжки.
Питание конкретного модуля проверяйте по его схеме; цифровой интерфейс — 3,3 В.

Используется схема пяти электродов: IN1=RA, IN2=LA, IN3=LL, IN4=RL,
IN5=V1. IN6 занят внутренним опорным сигналом Wilson, его внешний провод
оставьте изолированным. Цвета проводов и номера разъёмов модуля не определяют
эту распиновку: проверьте соединения на обесточенном устройстве.
Нужна внешняя цепь RLD согласно схеме модуля и
[документации TI, раздел 9.2.2](https://www.ti.com/lit/ds/symlink/ads1293.pdf).

## Запись в CardioScan

1. После проверки по USB отключите USB. Для измерений используйте автономное питание.
   Этот прототип не подтверждён как безопасный для подключения к человеку:
   аккумулятор сам по себе не заменяет проверку защиты и электрической безопасности.
   Не подключайте человека при подключённых USB, зарядке или неизолированном оборудовании.
2. Подключите компьютер к Wi-Fi **CardioScan-ESP32**, пароль **12345678**.
   Отсутствие интернета в этой сети нормально.
3. В приложении выберите Wi-Fi и начните запись. Адрес устройства:
   **192.168.4.1**, TCP-порт **3333**. Одновременно поддерживается один клиент.
4. Остановите запись в приложении для сохранения. На самой ESP32 файла записи нет.

Передаётся CSV: `timestamp_us,sequence,lead_I_raw,lead_II_raw,lead_III_raw,V1_raw,lost_samples`.
I, II и V1 — необработанные беззнаковые коды АЦП; III вычисляется как II−I.
Частота по настройкам АЦП — около 853,33 отсчёта/с; это не значения в мВ.
Программные фильтры не применяются. Serial служит для диагностики, запись идёт по Wi-Fi.

При переподключении очередь очищается, счётчики времени и последовательности
продолжаются с момента запуска ESP32. Пропуски определяются по `sequence`;
`lost_samples` отражает только обнаруженные потери внутри прошивки. Эти два
показателя нельзя складывать. Без клиента отсчёты не сохраняются.

`No DRDY for 2 s` означает отсутствие событий готовности данных: проверьте
DRDYB, питание, кварц и RSTB. При этом прошивка не подставляет повторные отсчёты.
